# v0.2.3

<!-- loopflow:release-notes=narrative;gate=safe -->

This release makes training and search spend less time on empty tensors, repeated checks and impossible mana payments. Fresh CUDA self-play uses the faster execution layout automatically, while new Limited construction APIs and documented learning components make it easier to build your own experiments. Upgrade for the large-board engine stall fix and broader card support; custom training code and older experiment readers need the migration steps below.

## Keep games and training moving

The performance changes target work that does not change the model or the legal choices. Measurements support faster execution on the tested workloads, not a claim of stronger play.

- **Large mana boards no longer hit the reported payment-search stall.** The retained 426-action replay took 33–35 seconds on its final step in 0.2.1 and 0.2.2; the repaired engine's slowest step was about 1.5 ms on both scalar and vector paths. Impossible-payment bounds and grouping interchangeable sources preserve legal actions and the first payment used for automatic tapping. Exhaustive worst cases remain possible with distinct sources. ([#504](https://github.com/loopflowstudio/manabot/pull/504))
- **Fresh CUDA self-play enables bucketed shapes and live-token attention.** Together they reduced the measured w384l8 learner step on an L4 from 882 ms to 202 ms. These began as opt-in experiments; the final behavior resolves both settings on for new CUDA self-play stages and records them in the regime. CPU and MPS stages keep them off, served evaluation remains opt-in, and search stays padded. Saved stages that omit the fields still mean off. Float32 remains the training default; these layout measurements do not establish learning equivalence. ([#497](https://github.com/loopflowstudio/manabot/pull/497), [#502](https://github.com/loopflowstudio/manabot/pull/502), [#489](https://github.com/loopflowstudio/manabot/pull/489))
- **Policy observations are validated once at admission.** Collection and learning reuse checked batches instead of repeating shape, reference, program and action-mask checks on every forward. Direct model callers must now supply admitted input. ([#480](https://github.com/loopflowstudio/manabot/pull/480))
- **Fresh local-update search uses compact evidence and native batch encoding.** Full per-Command witnesses remain available with `rollout_evidence="full"`; compact receipts cannot provide that audit detail. Recorded configurations that omit the evidence mode retain full-evidence semantics. Use `native_encoder=False` explicitly for the Python encoder; the default refuses a missing native batch encoder rather than falling back. ([#492](https://github.com/loopflowstudio/manabot/pull/492))

## Build and play more Limited decks

Deck builders now have a native legality API and a fixed pool corpus, while the engine supports more of the cards those pools contain. Construction legality, current-world admission and policy observability remain separate checks.

- **Build from a pool by name or in batches.** `managym.CardPool` and `managym.format.Limited` enforce at least 40 cards, pool counts for non-basics, no four-copy limit, and unlimited world-supported basics. The incremental builder exposes available picks and when it can stop; batched NumPy arrays use the same native rules. The published 1,000-pool TLA corpus retains human builds and a fixed 100-pool held-out split. Card-support changes do not move pools between splits, so comparisons should report the playable population. Builder models and training stages are not included. ([#466](https://github.com/loopflowstudio/manabot/pull/466))
- **58 of the 61 TLE bonus-sheet cards are defined.** In the reported sample, 995 of 1,000 TLA trophy decks imported normally. The implementation adds shared rules for alternative costs, counted tap payments, library reordering and other mechanics. Release to Memory, Lita, Mechanical Engineer and Heartbeat of Spring remain outside that delivered card set; the later token-definition split does not itself establish support for those cards. ([#469](https://github.com/loopflowstudio/manabot/pull/469), [#476](https://github.com/loopflowstudio/manabot/pull/476))
- **Policy input v10 is available explicitly; v9 remains the fresh default.** V10 appends player and card turn-state buffers for mechanics v9 cannot represent. A v9 encoder refuses an observation needing that state before writing buffers. Native and Python encoding, the model, LLM text and learning tokens all carry the new state. Default observation capacities can still overflow on TLA Limited games. ([#469](https://github.com/loopflowstudio/manabot/pull/469), [#466](https://github.com/loopflowstudio/manabot/pull/466))
- **Token identity and mana restrictions are explicit.** Tokens have their own definitions and resolve by `token.*` keys; copying printed characteristics does not copy token status, and tokens remain invalid deck entries. Mana restrictions now use typed spending predicates instead of silently treating unfamiliar subtypes as unrestricted. Encoders reject restrictions their input layout cannot represent. Scarecrow Guide and Supportive Parents are also defined. Academy curated asset packs still have a shared-printed-name limitation. ([#476](https://github.com/loopflowstudio/manabot/pull/476), [#496](https://github.com/loopflowstudio/manabot/pull/496))

## Assemble your own training and evaluation

Learning math, observation descriptions and experiment results are easier to use outside the recipe executor. The new APIs expose the contracts needed to build a loop or inspect a run without duplicating engine or storage logic.

- **Composable learning pieces:** `manabot.rl` contains returns, advantages, losses and update helpers; `manabot.training.updates` owns the maintained PPO and damped updates. The [training-loop guide](docs/training-loop.md) includes a complete self-play PPO example, also available as `manabot.training.loops.minimal`. ([#474](https://github.com/loopflowstudio/manabot/pull/474))
- **Named observation columns:** `managym.observation_layout()` describes axes, columns, encodings, sentinels and tagged rows without starting a game or importing Torch. Allocate from `ObservationSpace.shapes`; save package and world identity with collected arrays because catalog IDs are build-local. ([#468](https://github.com/loopflowstudio/manabot/pull/468))
- **Served evaluation accepts non-default checkpoint capacities.** Registration now derives observation and action ABI hashes from the checkpoint's own space, fixing erroneous `checkpoint observation ABI drift` refusals in frontier and learning-signal evaluation. This preserves compatibility checks rather than bypassing them. ([#488](https://github.com/loopflowstudio/manabot/pull/488))
- **Outcome tables belong to Etude.** Training logs `self_play_outcomes` through `Run.log_table`; consumers can read them with `RunData.read_table`. Shared report helpers give models readable names and draw one side of head-to-head comparisons. The frontier study found no clear advantage for the roughly 17× larger model at equal cost, with one training seed per size; it does not justify a larger default. ([#482](https://github.com/loopflowstudio/manabot/pull/482), [#494](https://github.com/loopflowstudio/manabot/pull/494), [#479](https://github.com/loopflowstudio/manabot/pull/479))
- **MLX is a measurement backend, not a new training default.** The optional Apple Silicon backend ports the policy and PPO learner step, with checkpoint conversion and parity tools. Its M2 pilot closely matched outputs and gradients at fixed weights and replayed a w160l8 update 1.67× faster than eight-thread CPU, but training, evaluation and the CLI still use PyTorch. ([#495](https://github.com/loopflowstudio/manabot/pull/495))

## Operational and compatibility notes

- **Dependencies and devices:** `manabot` now requires Torch 2.15+ and Etude SDK 0.2.16+. The pinned Linux training runtime uses CUDA 13.2, requiring NVIDIA driver series 580+ and Turing or newer hardware. Apple Silicon's local recipe defaults to CPU; MPS must be requested explicitly and requires Torch 2.15+ because older versions produced incorrect M2 gradients. The baseline recipe requires CUDA or explicit MPS. ([#470](https://github.com/loopflowstudio/manabot/pull/470), [#472](https://github.com/loopflowstudio/manabot/pull/472), [#482](https://github.com/loopflowstudio/manabot/pull/482))
- **Custom Python callers:** replace `manabot.training.learning.*` imports with `manabot.training.updates.*`; `objectives` becomes `ppo`, and shared math moves to `manabot.rl.*`. There are no compatibility shims. Before calling model forwards, use `admit_observation` from `manabot.model.admission`; plain dictionaries now raise `TypeError`. ([#474](https://github.com/loopflowstudio/manabot/pull/474), [#480](https://github.com/loopflowstudio/manabot/pull/480))
- **Engine API renames:** use `catalog_tokens` / `CatalogTokens`, `catalog_token_value` and `record_vocabulary` in place of `learning_catalog` / `LearningCatalog`, `learning_token_value` and `learning_record_names`. Old names warn and are scheduled for removal in 0.3.0. ([#468](https://github.com/loopflowstudio/manabot/pull/468))
- **Execution settings:** `MANABOT_BUCKETED_SHAPES` is no longer read. Use stage execution settings; for recipe comparisons, `--padded-shapes` disables both CUDA layout optimizations. `--bucketed-shapes` is now a deprecated alias scheduled for removal in 0.3.0. The pooled token-stream experiment has been removed: saved `token_stream="tables"` is accepted and dropped, while other values are refused with a reproduction revision. ([#485](https://github.com/loopflowstudio/manabot/pull/485), [#502](https://github.com/loopflowstudio/manabot/pull/502), [#498](https://github.com/loopflowstudio/manabot/pull/498))
- **Retained evidence:** runs using the retired `self_play_outcomes/table` format require an older reader such as revision `bf4e280f7`. Card, trigger and token changes update world content or learning identities; older checkpoints keep their original world bindings. Registered local-update players may need re-registration because their implementation source hash changed. ([#482](https://github.com/loopflowstudio/manabot/pull/482), [#484](https://github.com/loopflowstudio/manabot/pull/484), [#476](https://github.com/loopflowstudio/manabot/pull/476), [#492](https://github.com/loopflowstudio/manabot/pull/492))
- **Contributor feedback is faster:** six balanced parallel Integration groups and a single engine build reduced the slowest measured Integration job from 24m03s to 7m28s. The eight-minute ordinary Ubuntu job target is documented, not an enforced timeout; Engine Budget is exempt and macOS nightly is outside it. The 300-second single-test watchdog runs in each pytest worker. Separately, one flaky multistage recovery test was removed; its Etude metrics-writer race remains unresolved. ([#506](https://github.com/loopflowstudio/manabot/pull/506), [#490](https://github.com/loopflowstudio/manabot/pull/490), [#478](https://github.com/loopflowstudio/manabot/pull/478))
- **Experiment guidance now separates evidence from the decision.** Findings commit their question, comparison, strongest confound and cost cap before running; recommendations follow the observed result against the incumbent, rather than a preselected numeric verdict. Historical evidence stays unchanged. ([#505](https://github.com/loopflowstudio/manabot/pull/505))

## Small changes

- Beastmaster Ascension triggers once per attacking creature, and draw and keyword-action triggers retain the triggering player. Shared trigger descriptions more closely follow printed text. ([#484](https://github.com/loopflowstudio/manabot/pull/484))
- LLM card text renders `{X}` costs, and Academy recovery coverage includes alternative costs and selected tap payments. ([#469](https://github.com/loopflowstudio/manabot/pull/469))
- `transition_gae` rejects mismatched shapes instead of silently broadcasting them. Backend checkpoint loading no longer reads the removed token-stream field. ([#474](https://github.com/loopflowstudio/manabot/pull/474), [#499](https://github.com/loopflowstudio/manabot/pull/499))
- Release completion waits up to 300 seconds for PyPI's per-version listing after upload. Partial or mismatched inventories still fail immediately. ([#471](https://github.com/loopflowstudio/manabot/pull/471))
