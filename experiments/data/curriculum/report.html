An L1 warm-up does not help Allies versus Lessons

Spending the first quarter of training (32 of 128 iterations) on the L1 simple pool, then switching to Allies versus Lessons (L3), starts behind training on L3 throughout and only catches up. Same recipe, same learner transitions, six paired seeds, one continuous learning state across the switch in both arms.

Reading. The frozen rule calls a curriculum useful only if the six-seed interval for curriculum minus scratch at iteration 64 lies above +5 points. Against greedy the interval -0.8 [-4.0, +2.5] lies inside ±5: no useful effect. Against heuristic -2.3 [-5.6, +0.9] is inconclusive only because its lower bound crosses −5. Which anchor decides awaits MTG-153's heuristic-versus-greedy pairing; neither can yield “useful”.

What ran

  • Training: Etude run 8cc849175eab, one L4, 12 fits in 5,371 s, source adcf54e3. Recipe 64x2, 64 streams × 64 transitions, 128 iterations = 524,288 learner transitions per fit. Both arms carry weights, EMA, Adam and the schedule clock across iteration 32; only game streams and RNGs restart.
  • Scoring: four rented 8-vCPU CPU pods. Held-out L3 matrix (four deck-role cells, both play orders, 50 deals) against heuristic, greedy and random at 0, 32, 64 and 128, with frozen-initialization controls.
  • Parity: 8 of 9 initialization cells re-scored the Mini's complexity cells exactly: 3,200 games, 0 differing.
  • Retained failures: a first scoring attempt failed admission before any game (fixed in 112aff3f); three EU-SE-1 pods never opened SSH and were deleted; a slow pod's 13 unstarted units moved to other pods. No cell was rerun.
  • Not tested: L2 first, other switch points or shares, weights-only transfer, longer horizons, mirror training.
