# Same-host evaluation concurrency probe

2026-10-17. A timing and equivalence probe under MTG-135's inclusive$50 campaign.
Serial CPU evaluation may constrain the scientific learning comparison's budget.
Measure independent ordinary evaluation CLIs concurrently before using a speedup
in admission. No calibration score selects a model or training treatment.

One RTX5090 rental, quoted at most$1.25/hour, with at least four CPU cores of
quota and48GBRAM. One attempt, no automatic retry, at most30 command minutes and
a$1.25 allocation. Setup600seconds, CUDA60seconds, training180seconds, each
evaluation command600seconds; all remain subordinate to the outer deadline and
240-second output-retention reserve. Reserve the allocation in the inclusive
ledger before launch and confirm provider deletion before releasing its cap.
At most two campaign rentals and one scheduling owner remain active.

Build once, admit CUDA, and create a width384/depth8 initialization through one
ordinary64-stream update (4096transitions), reserved seed13598. Score only its
retained initialization. Same-host serial and parallel cases use that exact file,
ordinary stochastic one-pass CPU inference and one Torch thread per game.

First run one eight-leg deal block per greedy/random anchor serially. Then repeat
each complete panel twice, in four concurrent independent CLI processes and
separate output directories:16serial games and32parallel games. Use reserved
deal1359800000, all four deck-role cells,120seconds/10000commands per game and
ordinary replay validation. The repeated reserved deal is timing evidence only.

Every panel must be complete, terminated and replayed. Require identical retained
registrations, checkpoint/recipe identity, seeds, observations, offers, chosen
Commands, pre/post-state digests, outcomes and all other decision-trace fields.
Exclude only measured latency fields and trace hashes that include those latency
fields. Equal score totals alone are insufficient. Preserve originals and record
the canonical comparison digest. Any mismatch or incomplete panel fails the probe;
stop active siblings and start no queued work after an observed command failure.

Report16-game serial wall time,32-game parallel wall time, and equal-work speedup
as twice serial time divided by parallel time. Include coordinator/admission cost,
hardware/quota and retained child timing. A future allocation must bind its CPU
concurrency and budget to measured costs with margin; this single-host initial
policy probe does not establish universal scaling or learned-policy game lengths.
