# Semantic kernel evidence: w8

This corpus records current-world terminal games through the reference and
optimized paths, including the compiled sacrifice pack in both seat orders.
Earlier corpora are retained unchanged. The Phase matrix is the inherited
pinned source inspection; it makes no external-engine claim for new cards.

Regenerate only this development corpus with:

```sh
cargo run --manifest-path managym/Cargo.toml --bin semantic_conformance -- record --root conformance/semantic-kernel-w8-v1
```

World freeze and release certification are separate checks.
