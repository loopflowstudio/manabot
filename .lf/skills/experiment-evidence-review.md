Check every declared run and game, identities, failures/costs, paired analysis,
training exposure and scientific limits. A setup, merged PR, complete schedule or
tiny successful update does not by itself demonstrate learning. An inconclusive
result may fulfill an honest protocol; missing required evidence is not acceptance.

Use the bound loop protocol. Advance only when the accepted outcome is delivered.
Iterate to execution only for a specific missing/correctable portion still covered
by the same frozen protocol and explicit authority; require reconciliation before
any retry. Changes to hypotheses, source, decks, bounds or analysis require a new
prospective design and review, so block this execution edge with that direction.
Do not launch another campaign, enlarge spending or waive exposure acceptance.

stop without declaring the Task complete.
