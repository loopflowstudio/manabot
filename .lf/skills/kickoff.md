# Etude kickoff evidence

For play/checkpoint designs, inspect the actual `GameSession`, `Trace` writer,
table protocol and selected-world loader before proposing another session or
identity store. The current arena fingerprint helper in
`manabot/sim/teacher1_evidence.py` constructs an Interactive mirror; its output
must not be treated as the Allies/Lessons runtime identity without checking the
matchup inputs. Never rewrite frozen experiment fingerprints to bridge a mismatch.

Distinguish canonical historical decisions from complete execution: automatic
passes are not human decision rows. Verify what the current trace actually
retains before claiming policy-free reconstruction or crash durability.

Synthetic checkpoint tests prove loader plumbing only. Real candidate admission
requires the supplied bytes and compatible world; real human completion/return
requires dated human evidence. Preserve these as separate proof boundaries.
