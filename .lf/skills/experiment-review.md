Review with the person what the result establishes and whether the experiment
is done.

Check that each claim matches its evidence, that exploratory numbers are not
presented as findings, that a finding answers the question committed before
its runs, and that its recommendation follows from the result read against
the incumbent rather than from a bar set in advance. A merged PR, a complete schedule or a tiny
successful update does not by itself show learning. An inconclusive result can
finish an honest experiment. Read the report from the top as its reader would:
it must answer its questions in plain words before tables, with provenance in
a closing appendix. A report that opens with counts, ledgers or execution
status is not done.

Use the bound loop protocol. Advance when the outcome is delivered. Return to
the run only for a specific missing or correctable portion of the same question
within the spending already approved. A different question is a new experiment.
When a finding changes what we know, update the README and research program in
the same delivery. When a needed judgment is unavailable, record it in the
report and stop without completing the Task.
