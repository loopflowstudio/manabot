## In this repository

Never induce load to test anything ([TESTING.md](../../TESTING.md)); a large
constructed board run once is a workload. Keep runs, builds and `ETUDE_HOME`
under ignored `.runs/`. Finish the Rust edits before building the native
extension, then build it once per pass: a release build takes minutes.

Academy browser scripts can wait for a ready offer with
`[data-testid=action-option]:enabled:not([aria-disabled])`. A press during an
opponent read-out only ends the read-out. Playwright's release configuration
starts the payment fixture server for `e2e/mana-payment.spec.ts`.
