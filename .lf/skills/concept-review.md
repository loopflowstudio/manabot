For engine, RL, and training infrastructure (`managym` and `manabot` outside
Academy and CLI surfaces), the user is the algorithm or caller, not a human
operator. Judge concepts, APIs, and data layouts by what is optimal for the
training, search, and evaluation algorithms that consume them—throughput,
memory and cache ownership, thread safety, statistical validity, and
composability—rather than human UX.

**Skip a pass that adds no concept.** In a Graph with nobody there, when the
work since the last review only authored cards or moved callers onto types,
records and APIs that `scratch/concept-review.html` already covers, report
"nothing to change" in one line and leave the page alone. Review, and rewrite
the page, when the work added or changed a rules type, an observation or token
kind, a Command or an offer shape.
