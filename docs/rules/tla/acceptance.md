This audit reconciles the allocation with the native catalog and directed behavior
witnesses on the T7 implementation stacked on published T6 `01ed2fbcb`.
The [allocation](allocation.jsonl) remains the planning authority; this document
is evidence navigation, never an admission allowlist. Definition is support.

## Denominators and boundaries

- 286 card identities / 294 faces: all have native definitions. The eight back
  faces are reachable through their front definitions and cannot enter a deck
  independently. 278 front definitions first appeared in TLA; five basics and
  three reprints use their first-printing sets.
- Nine fixed token templates are registered as tokens. Copy is a marker for
  characteristics copied from an existing definition, not a tenth fixed token.
- Treasure is the one explicitly unallocated adjacent-product row. Its
  `in_tla_closure: false` and `planned_pr: null` are intentional, not a missing
  TLA implementation.
- `definitions::tla_allocation_has_every_face_and_fixed_token_in_the_catalog`
  checks all 305 allocation rows, eligibility, face identity and token closure.
  This inventory check says nothing about interaction correctness.

The table preserves every face's allocated obligation and links its implementation
and a concrete behavior witness. Witness selection uses the existing test-name
reading aid, then favors the card's own named behavior. A test mentioning a card
is not proof of every clause; the linked test and definition show the bounded
claim. Shared tests for basics and reprints remain with their existing owners.
Use `uv run python managym/cards/tests/cards/coverage.py` to list all witnesses,
including additional negative and cross-card cases omitted from this compact table.

new player-control proofs do not combine control with copied Bloodbending,
Firebender Ascension's retargeting, Sozin's multi-zone naming/search, or repeated

covered; a Bloodbending + Kuruk extra-turn combination is not separately played.
