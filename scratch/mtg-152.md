## Static card-pool and offer-order audit (2026-10-18, no games)

Source: `content/semantic/v1/two_deck.source.json` main decks;
`managym/src/flow/triggers.rs::legal_targets_for_spec` and
`flow/action.rs::pending_choice_action_space`. No observation-side reordering.

Target offers are in **absolute engine order**: for `creature_or_player`,
Player(0) then Player(1); then player 0's battlefield, then player 1's;
`spell_or_permanent` lists stack spells (top first) before that. Greedy takes the
first non-decline offer, so its target side is a function of its seat
(`player_index`), not of any card judgment. Arena legs alternate seats
(`player_a_seat = leg % 2`), so each MTG-137 greedy cell mixes both behaviors.

Side-ambiguous targeted cards (others are side-restricted by selector):

| Deck | Card (count) | Effect | Greedy at seat 0 | Greedy at seat 1 |
| -- | -- | -- | -- | -- |
| Lessons | Firebending Lesson (4) | 2/5 dmg to creature | own creature if any | opponent creature if any |
| Lessons | Igneous Inspiration (2) | 3 dmg creature/player | **always itself** | always opponent face |
| Lessons | Divide by Zero (2) | bounce spell/permanent MV≥1 | top stack spell, else own permanent | top stack spell, else opponent permanent |
| Lessons | It'll Quench Ya (2) | counter spell unless 2 | top stack spell | top stack spell |
| Allies | Fancy Footwork (2) | untap +2/+2 up to two creatures | own creature first | **opponent creature** if any |

Side-restricted (correct regardless of seat): Earth Kingdom Jailer (opp ≥MV3,
optional; greedy takes it), Badgermole Cub (own land), Allies at Last (own
sources + opp victim), Yip Yip (own). Learn can fetch sideboard Firebending
Lesson / It'll Quench Ya. Removal does dominate pumps in the pool (Lessons: 10
harmful targeted of 23 nonland; Allies: 2 beneficial-any).

Implication (hypothesis, unmeasured frequency): greedy-as-Lessons damages
itself in seat 0 and greedy-as-Allies pumps the bot in seat 1, so the
greedy-Lessons cells (AvL, LvL) partly measure the anchor bug. Seat-split
counts were added to `TargetCount` so the remote audit can confirm frequency.
A fix (question a) is cheap and well-specified: a separately versioned
`scripted_greedy_v2` choosing by effect polarity (harmful → opponent side,
beneficial → own side), keeping v1 frozen. Implementing it before measurement is
reasonable but its headroom still needs remote evaluation.
