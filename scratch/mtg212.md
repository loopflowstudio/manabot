## Findings that change the implementation

OpenRouter's [official Jev guide](https://openrouter.ai/blog/insights/what-is-jev/)
documents `typesafe/jev-1.14` at `/api/alpha/decisions`. Requests contain state
and typed questions; Choice returns a selected criterion and probabilities.
Its receipts use `input_tokens` / `output_tokens`, cost, returned model and
provider. The [TypeSafe API](https://docs.typesafe.ai/api/system-one) confirms
the typed response contract. The public `/api/v1/models` response inspected
on 2026-10-28 contained 456 entries and only `typesafe/jev-router` under Jev;
that is a router to other models, not the decision model.

`manabot/llm/openrouter.py` fixes its endpoint, identity, request and receipt
to chat completions. The game summary and historical readers use that receipt
shape. Changing `model_id` alone cannot implement Jev's typed Decisions API.

`experiments/haiku-mtg183.md` and `experiments/qwen_mtg183.py` identify final
raw u5950, run `f3748bcabac8`, SHA-256
`4f2ad656ba036a33d527212a7ac2badf2c5b9db136916f730846b07eef2fbea4`,
1,071,166 bytes, world w13. They do not establish that it is the best-rated
checkpoint. The local `~/.manabot/mtg183-eval/state.json` has 54 checkpoints,
`done=false`, `endpoint=null`, observed_at 1792902546.0715132. It is stale
evidence, not a current empty rating plan. MTG-183's Task read succeeded but
did not provide its combined rating database. The historical notes locate

## Proposed corrected design

- Extend OpenRouterSession with typed Decisions requests and receipts; preserve
  chat receipts and readers without fabricating completions for Jev. Send the
  complete viewer-safe observation and legal actions; reject unsupported
  choice/context cardinality before sending. Return one bound reference to the
  native runner. Provider errors stop; probabilities/confidence never override
  the chosen action.
- Before scoring, select the checkpoint from a dated combined evaluation and
  retain its artifact ID, bytes, digest and selection rule. Bind matching
  historical source/native/input artifacts. Keep capture, stale rejection,
  Command execution and replay in the existing game runner; use shared policy
  inference where that runtime supports it. Unresolved inputs are in
  [questions.md](questions.md).
- Add one bounded experiment driver with a frozen schedule, pilot boundary,
  durable admission and spend reservations before requests, and no automatic
  replacement games. Reserve conservative request charges, including unknown
  usage and any possible repair, before dispatch; stop on unpriced attempts
  with their reservation retained. Reported cost alone is not a billing cap.
- Preserve the full target: per-seat/overall wins and intervals, valid and
  failed games, repairs/fallbacks, latency, pilot tokens and decisions, projected
  1,000-game cost, and per-game/total inclusive spend. Statistical treatment must name
  the seeded-deal sampling unit and budget-based stopping limitation.
