What was built

A TLA trophy evaluation can keep up to 64 native games in flight per Etude game process. A finished game frees its slot for the next compatible game. Each deal still crosses both decks and seats, and Etude receives its result after all four games settle and replay. Automatic runtime selection is CUDA, MLX, MPS, then CPU. On Apple Silicon, MLX is selected when the optional extra and Metal are available.

How to try it uv run --no-sync python -m experiments.eval_throughput --output-dir ".runs/ship-review-$(date +%s)" --device mlx --runner vector --slots 64 --deals 4 --checkpoint .runs/eval-throughput/policy/00002000-raw.safetensors

How it works

Etude streams deals into the native arena

Closing the callback also closes the game stream. The historical float32 name is reused. Reduced-precision jobs get their own report and tournament name.

The game worker prepares one batch per checkpoint

Memory blanking is a seat choice, including when two seats share weights. Each seat samples its own legal row using its recorded seed. The host-admitted batch is ready before the sampler awaits Etude. Malformed logits are reported against this checkpoint.
Contiguous arrays for direct transport

The five original strided arrays were relation_rows, name_rows, group_last, compact_attention.batches and compact_attention.slots. Gate 1 also found a sixth, effects.detail_kinds, on rounds with live effects. The final preparation paths produce contiguous storage for all six. Compression converts lookup columns directly, removing intermediate copies.

Each match owns its queued legs and its failure

A compatible match supplies its next queued leg. On a fresh vector, the oldest waiting deal picks the layout. Removing the affected match also removes its queued legs. Slots belonging to unrelated checkpoints stay live. The seed travels with the deal to the free slot. Etude receives held failures before the runner requests replacement grants.

The pass 7 regression reproduced a negative grant with 10 failures and nine slots. After admission and reuse adopted one layout key, the final nine-slot test queues eight healthy deals with a genuinely different layout, fails two deals sharing one checkpoint, and checks that both errors arrive before a new grant. The unrelated active deal completes and replays all four legs, and the deferred deals succeed. The checkpoint failure is injected in the fixture. Final regression

Key data structures and APIs

Deal and PairingSpec
Deal supplies the trophy pools, seed and precision. Scalar and vector play share PairingSpec for the matchup, four-leg crossing, limits and precision.
Matches.take(n) and play_many
Etude grants matches with seat agents. The async generator yields (match, Result | Exception) when a deal settles. Scalar jobs declare an async play callback.
ObservationBatch, ObservationSelection and Prepared
Managym supplies packed v11 observation rows. The worker gathers checkpoint-specific row coordinates, resolves joins and legal masks through prepare_batch, and sends Forward([prepared], rows=prepared.batch). Backends return float32 masked logits with shape [batch, action slots].
ActiveMatch, PendingLeg and VectorLayout
A match holds its pending legs in grant order. One compatibility key governs admission and reuse from buffer shapes, overflow policy and vector-wide decision-memory settings. Mana payment stays a seat setting.
EvalTarget and AGENTS, AGENTS_BF16, AGENTS_TF32
EvalTarget names the internal runtime choice behind MANABOT_EVAL_DEVICE. Job declarations select the agent set and persist precision in the compute class. TF32 requires CUDA.
SlotLoad.fresh(..., seed=...) and RecordedVectorEnv.take_slot_record
Seeded slot loads preserve the deal’s identity during backfill. The recorder detaches the finished game before slot reuse. The managym-game-v1 record carries Commands, offers, live viewer frame evidence and digests. The Etude result retains outcome, behaviour and card evidence.

Trade-offs and invariants going forward

  • Stable seeds and evidence. Float32 retains its existing environment and compute-class identities. BF16 and TF32 use suffixed tournament names and carry declared precision. The paired-deal and player seeds stay stable across precisions. A precision can choose a different action and still replay the exact action it recorded. Scalar and vector evidence is compared field by field because raw record hashes also contain runner mode and timings.
  • Optional inference and training extensions. Evaluation keeps eager Torch. On MPS, full-graph compilation failed the binding check. A permissive run matched eager logits within 1e-5, took 19.0 s on the first call, and took 1.620 s over 36 warm calls versus 1.315 s eager. Checkpoints carry no training-precision field, so evaluation precision stays a job declaration with float32 as the default. Evaluation joins ordinary memory rows. Training’s retained memory fold trees keep their own preparation and checkpoint compatibility. Compilation probe · Fold-tree boundary
  • Scheduling and limits. The oldest held deal chooses the next vector layout after a drain. Each game’s 120-second gameplay budget accrues its share of live round time. The throughput CLI uses the same budget. The Command cap and Etude job deadline also bound a trophy run.
  • Data boundaries. The game worker caches metadata by path, SHA256 and size under Etude’s immutable artifact contract, forwards prepared observations, and delivers viewer-safe replay evidence. Run lf security-review before delivery to check artifact admission and the observation and evidence boundaries.
