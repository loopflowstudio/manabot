What works, what I couldn't reach, what's still wrong

  • Works: every real-card board in the plan's table pays in some order or the cast is withheld. Across 1,090 random games in both payment modes there were no empty decisions, errors or debug panics. Mid-payment snapshots restore exactly.
  • Unreachable with real cards: a fixed tap that opens a Heartbeat bonus choice needs a fixed multi-color land, and the catalog has none (only CC, RRRR). A static grant that ends while its activation is paid has no real card either. Only the Rust fixtures (fixed_mana_tap_can_open_a_bonus_choice, owned_activation_keeps_its_targets_and_effect_when_mana_ends_the_grant) reach them, and so does the hover-preview needs_choice path. Academy itself wasn't driven, because the plan changes no Academy surface.
  • Still wrong: nothing found. Watch item: debug steps on large coupled boards reach ~300 ms. Engine Budget (release) remains the check for that.
