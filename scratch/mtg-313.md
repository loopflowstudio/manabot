## `Moved` wording correction (2026-11-12)

Concept review found that changing the shared selector to "objects moved this
way" reworded existing flicker, unearth and untap effects in Academy and the
LLM observation. The correction restores "it" there and describes counts separately.

Implemented:

- `selector_description(Moved)` returns "it" again, as on main.
- `value_description` names the counted result itself for `Objects { of:
  Moved, .. }`: "the number of cards moved this way", and with a predicate
  "the number of creature cards moved this way" (no "among objects"). This
  also repairs main's "the number of it" for discard/draw. Other selectors
  keep "the number of {selector}" / "the number of {predicate} among {selector}".
- Count assertions use those strings; a flicker regression assertion preserves
  "Exile target creature you control. Put it onto the battlefield under its
  owner's control". Source inspection found that main's wording is "Put it",
  not the earlier plan's "Return it" shorthand (see `scratch/questions.md`).
- Rules, tokens, learning tokens and input layouts are untouched.

`EffectValue::Objects { of, predicate }`, both token keys and the Zeppelin
definition were re-examined and stand.
