named layouts for inputs 1–9 and both event projections; Python dictionary API
and stub; discoverable v9 recommendation with v6 implicit defaults unchanged.

and widths. The observability guard references the same names. No game behavior,
array values, capacities, checkpoint identities or worlds were changed.

## Delete — do not maintain

names from the layout authority. Existing public Rust index constants now refer
to that authority. Removed the observability tests' `PERMISSION` alias and
offset arithmetic; they read named permission columns directly.

`observation_layout::ValueLayout` shares value semantics across columns and
scalar arrays, removing repeated descriptions and borrowed card-column metadata
for masks and definition arrays. The Python dictionary contract is unchanged.
Version selection and recovery guidance lives in one docs section; the v8
example links to it. No public API or stored data was retired. No deletion
targets remain.
