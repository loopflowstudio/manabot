What the Manabot helpers may contain
HelperResponsibility, not hidden execution
training_binding / load_stateValidate world, model and input shapes; restore learner, optimizer, EMA and RNG state. No leases or remote retry.
open_collectionAcquire native streams, restore cumulative counts and attach durable game-error capture; close resources. No training loop or scheduling.
collect / learnProduce a batch; perform the learning update and return state/metrics. Mutation contracts must remain explicit for model/optimizer resources.
save_state / export_checkpointAtomic mutable resume file versus immutable update-named policy file; world binding and source revision remain intact.

The helper implementations are not supplied by this sketch. Failure capture, outcome metrics, backend selection, seed streams and checkpoint bindings must survive their extraction. They cannot simply be deleted to achieve this line count.

track, log, log_table, checkpoint, function jobs, evaluationExisting Etude concepts; import paths here are illustrative.

Etude sees a callable, arguments, clocks and opaque files. The same tools must work for a supervised learner or a simulator without importing Manabot. This is a proposed boundary, not a newly implemented framework.

4. One interruption, end to end

  1. The loop completes update 24 and atomically saves state.pt.
  2. run.stopping() becomes true. Manabot saves state and raises Stopped; Etude records a planned stop.
  3. If the launch allows another attempt, Etude restores the out directory before calling the same function. Frontier’s shown max_attempts=1 deliberately does not auto-retry.
  4. Manabot reads update 24, reopens native streams, and starts its next update. Optimizer and EMA survive; in-progress games do not. This does not promise bitwise equivalence to uninterrupted training.
  5. A target-only continuation creates a new run with copied out. run.until supplies the new target; the parent’s recorded checkpoint bytes remain unchanged.

Historical TrainingRegime stays readable for evidence. It stops being the language an executor interprets for new training. Extract reusable learning settings to their own defining modules; do not retain a new-loop → old-regime → old-executor validation dependency.
