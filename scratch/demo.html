Cards filed by first printing; support by definition

World w16, PR394. This follows Jack Heart's 2026-10-29 direction ("simplify simplify simplify").

What changed

  • No qualification gate. qualifications.json, inventory.json, the T1 clause review and the closure-hash check are deleted. A card is supported when its set file defines it with a typed program and does not mark it incomplete.
  • One incomplete list. tla::INCOMPLETE names 14 TLA cards that fixed setups still use, each with its missing behavior.
  • The world pool is every defined card. tla-pool-v1 covers every set: 115 supported cards, plus tokens, incomplete cards and native cards, all marked unsupported. managym.set_cards(["tla", "lea"]) narrows it to chosen sets.
  • First printings. Basic lands are now lea.plains … lea.forest. cards/native.rs is gone: Counterspell, Serra Angel and the rest sit in their first-printing set files (lea, por, isd, ori, sth, rtr, grn, ice, vis, stx, mkm). Crossroads of Destiny is a rules fixture in cards/fixtures.rs.

Try it

uv run python -c "
import managym
print(managym.unsupported_cards(['Forest', 'Lightning Bolt', 'Cat-Gator', 'Counterspell']))
print(len(managym.set_cards(['tla', 'lea'])))
"

This prints ['Cat-Gator', 'Counterspell']: Cat-Gator is marked incomplete and Counterspell is native. Forest and Lightning Bolt are supported.
