# Audit assumptions and limits

- Use the official TXT currently linked by Wizards (effective September 25, 2026), rather than guessing a future rules revision from the session date. Preserve exact raw-byte digest; no claim about unpublished updates.
- Unknown is a completed triage outcome, not conformance certification. Rule families can share inspected candidate owners; subrules need their own proof before upgrading status.
- Local validation ceiling: 15 minutes per cold Rust command, 3 minutes per warm focused command, 2 Cargo build jobs, 120 seconds per Python check. No random-game search or load loop. Directed matrices have fixed node counts (192 SBA, 2,688 mana cases maximum). Run each selected suite once unless a failed edit requires repair.
- No production rules or world change is necessary for the first draft. Add directed behavioral evidence and authoring/ownership documentation without a competing payment rewrite. CI topology changes require timing evidence; measurement instrumentation may be drafted without changing coverage.
