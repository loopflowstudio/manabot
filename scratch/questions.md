# Open assumptions and deferred choices

Settled rationale for built slices lives in git history (this file before `realign` on 2026-11-24).

- `ObjectSelector::Zone(ZoneType)` (owner-scoped zone cards, kept for hidden-zone sampling) and `ZoneMatching { zone, owner: You, predicate }` overlap. Only `fin.rs:153` and `tle.rs:937` use `Zone` over a public zone. Folding them changes those cards' learning tokens, so it stays out of MTG-420; revisit if a third public-zone form appears.
- `can_add_clause_target` owns "that share a creature type". Only activation offers look ahead for a remaining partner while the minimum is unmet; no printed trigger or spell uses a shared-type clause yet (Secret Tunnel is an activation). Trigger-mode and activation availability count `min` candidates without the partner rule, matching `legal_spell_modes`.
- `Condition::AttachedCountersAtLeast` sits beside `SourceCountersAtLeast`; a general `CountersAtLeast { on }` would rename TLA learning tokens. Left until a third subject appears.
- `agent::observation_json::tests::historical_captures_move_battlefield_and_spell_rows_onto_their_records` fails at its last assertion on base `25ba418a2a` too. It belongs to the merged observation/legacy-input work; left for gate.
- CR 603.6a entry-attached Aura suppression: no catalog card triggers on an enchantment, Aura or any permanent entering, so `ZoneEntry.attached_to` has no card witness. Witness it when such a card is defined.
- `TriggerCondition::SourceDealsCombatDamage` is a separate variant rather than a `combat` field on `SourceDealsDamage` (which "parameters are fields" would prefer) because the field would change Cecil's serialized learning token. Revisit if a third source-damage trigger appears.
- Kindred permanents read as non-creatures for creature types: `Characteristics::has_all_creature_types` and `finish_object` (`layers.rs:560`) test `is_creature()`, though CR 205.3d and `subtype.rs` give Kindred creature types. No catalog card is Kindred, so there is no witness; widen both to "has creature types" when the first Kindred card is defined.
- `departed_copiable_values` gives catalog DFC faces to any departure without a snapshot, tokens included, matching the live rule in `transforming_faces` (no token check); no catalog token has a back face, so the plan's `!lki.battlefield.token` guard would be a second rule with no witness.
- With hidden manifests, a constrained `PossibleWorldSpace` weight also counts ordered manifest fills (a factor shared by every world in the space), so its `total_weight` scale differs from the unconstrained space's. Relative world weights are exact. Normalizing would need non-integer weights.
- `selection_hidden_allocations` enumerates manifest name fills over every unseen name; cost grows like C(names + M − 1, M). Fine for Manifest Dread's one-at-a-time manifests; revisit if a card makes many manifests at once.
- `Effect::exile_linked` (constructor for a `Move` with `LinkedExile::WithSource`, Batch 1 links) and `Effect::ExileLinked` (the Hama/Azula cast-grant exile) share a name for different concepts. Renaming either changes card code and possibly learning tokens; left for a naming pass.
- A manifest's entry can never pause today: `Game::manifest` runs an immediate batch, which panics on any choice but entry-copy. If a card ever applies two replacements to a manifest entry (or manifests through a retained frame), that path needs a retained caller; the hidden-entry visibility it would need is already in place and witnessed with a constructed batch.
- `pending_trigger_definition` now falls back to `ANONYMOUS` for a departed face-down source without LKI; `place_triggered_ability_on_stack` expects `source_face` to resolve it. Every departure from the battlefield records LKI, so no path reaches the fallback with a face-down source; noted in case one appears.
- Seed replay (`GameSnapshot.to_replay_json`) needs a journaled prefix; every constructed fixture (Rust `Scenario` injections and Python `scenario_*`) is an unjournaled mutation and is refused. The closing pass replays the choices a natural seed-4 game reaches (manifest selection, Healer kicker, Lost Days' owner position; `tests/env/test_game_snapshot.py`). Ragnarok's meld order, the Horde/Driver/Fire Crystal trigger orders, the named Coil and the Batch 1 fixtures keep their native restore-based fork, stale-rejection and commit-once checks; seed replays for them need either natural decks that reach those positions or journaled scenario interventions (new behavior, not this Task).

The native witness `hidden_selection_manifest_fill_leaves_the_committed_library_cards` covers sampling while the selection's cards are committed; no natural fixture pairs a pending selection with seeded searches.
