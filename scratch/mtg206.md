# MTG-206 — card evaluation on Etude blocks (plan and remaining work)

Accepted design: the Task directive (Jack Heart, 2026-10-27). Assumptions in
`scratch/questions.md`.

## Shape (implemented)

- `card_metrics.CARD_ROLLUPS`: `card_deals` (card_counts ⋈ card_plays, by card,
  deal, on_play, deck, opponent_deck, source_commit, player, opponents; where
  eligible; gp/oh/gd/gih/gns and `_won`) and `game_deals` (card_plays, same
  splits plus eligible, outcome; `wins`).
- `card_evaluation`: `play_card_match` and `trace_card_tables` return
  `etude.eval.match.Result`; the replay worker's evidence files are a scratch
  handoff (`_handed_over` reads, verifies, deletes). `evaluate_cards` holds with
  `rollups=CARD_ROLLUPS` and a temporary scratch folder; rows drop `evidence`.
- `card_query`: `card_db` = `statsdb(..., rollups=CARD_ROLLUPS)`;
  `card_variants(db, selection, dimensions)` computes every combination in one
  grouping-sets pass per rollup (single-valued dimensions are not split);
  `card_data` is its empty combination. GIH intervals: one
  `estimate(deals, wins, opportunities)` per combination (etude-sdk 0.2.10,
  EXP-30). `load_game`/`audit` use `read_blobs`.
- `card_page.page_data` = `card_variants` over all five page dimensions.
- `mtg186_cards` returns `Result`, declares rollups, hands evidence through
  scratch. `elemental_long_eval.done_keys` reads sealed blocks.
- `experiments/mtg206_cards.py`: the small L4 smoke (MTG-186's card match on 10
  fresh deals, run `mtg206-cards-l4`, experiment `mtg206-cards`, ≤ &#36;1).
