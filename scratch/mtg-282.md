Deliver three outcomes of MTG-282, following `docs/deck-building.md`:
a published, loadable 1,000-pool corpus (922 playable) with a frozen split;
tensor-native Limited rules with Python picking; public game rows without
recovery enabled. Outcome 4 (named models, module stages) left the Task on
2026-11-12; see the direction below. No training experiment, new learner,
world change, or existing-stage move.

## Preserved boundaries

Limited rules, tests and bindings now use `format::limited`; there is no
`cards::limited` compatibility surface. Pool derivation admits entries and
records unknown-card exclusions; malformed lists still fail derivation.
Existing private game attempts remain recovery evidence; aggregate counters
remain summaries. Frozen single-agent
recipes and historical trophy corpora keep their serialized meaning.

## Direction: tensor-native rules — 2026-11-12

Jack Heart, on rules readable as data: "definitely make it \"tensor native\"".
This replaces the question-5 default (no array form in this Task).

- Card axis is the engine's `card_def_id` (`managym.CARD_DEFINITION_COUNT`),
  the same index jace's adapter already maps through.
- `Limited.min_cards` (40) and `Limited.basics` (bool `[cards]`) are readable
  data, so a GPU builder writes `(deck < pool) | basics` itself.
- `CardPool.counts` is int `[cards]`; a pool can also be made from counts.
- Batched native forms over int `[n, cards]` pool and deck counts:
  `limited.selectable(pool, deck, max_cards=...)` -> bool `[n, cards]` and
  `can_stop` bool `[n]`; `limited.legal(pool, deck)` -> bool `[n]`.
- `limited.build(pool).select(name)` stays, as a thin wrapper over the same
  native function; a directed test proves name and array forms agree.
- NumPy at the boundary, like the observation encoders; no torch in managym.

Jack Heart, on copies still available: "sadd it". Direction: the builder
reads copies, not only legality. `limited.available(pool, deck, max_cards=...)`
returns int `[n, cards]` copies that can still be added (pool count minus deck
count; for basics, the slots left under the cap; all zero at the cap) plus
`can_stop` bool `[n]`. The legal-pick mask is `available > 0`, so this replaces
the separate bool mask. Name form: `build.available` is `{name: copies}` and
replaces `build.selectable`.

Jack Heart, on jace's land-count range in the rules and its exact deck size:
"agreed, dont do either of htese". Limited keeps a 40-card minimum with a stop
choice and no land-count rule; deck shape is for the builder to learn.
- Steer 39c19262: copies, not masks — `limited.available(pools, decks,
  max_cards=60)` -> (int `[n, cards]`, bool `[n]`); `build.available`
  replaces `build.selectable` (no alias); no bool-mask method.
